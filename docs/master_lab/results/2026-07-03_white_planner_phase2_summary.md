# White Planner Phase 2 Summary

生成: 2026-07-03

## 目的

白対白を詰める次フェーズとして、既存の単発評価係数追加ではなく、`white_planner` に「自ターン終端盤面 + 相手応答読み」を使う実験基盤を追加した。

## 実装

- `scripts/white-planner-phase2.ts` を追加。
  - 同一局面で `white` と `white_planner` の判断を並列比較する。
  - 判断時間、差分数、planner が実際に選んだ差分、差分サンプルを Markdown/JSON へ出力する。
  - 盤面表示に `shield` と `focus` を出し、ためた状態の引き継ぎを読めるようにした。
- `white_planner` の終端評価を調整。
  - ターン終了時に残る `focus` を、次ターンの攻撃準備として終端盤面評価へ反映。
  - 脅威下・レベルアップ余地ありの `shield` を終端盤面評価へ軽く反映。
  - 探索候補から `focus` / 有効盾が落ちにくいよう、候補補完を追加。
  - 終端盤面だけで初手を決めないよう、初手評価の大幅悪化にはガードを追加。
  - `white_planner` では通常評価側の終端比較罰則を切り、プランナー採用ゲート側だけで終端探索を使う形に分離。

## 所感

現時点の `white_planner` は、探索の土台としては前進したが、既存 `white` の置換候補ではない。特に、白ミラーでは既存 `white` の局所判断がかなり強く、終端盤面探索が少しでも「削り」「撃破」「配置の手順価値」を見誤ると勝率を落とす。

一方で、差分検証スクリプトにより、どの局面で planner が既存 `white` と違う判断をしたかをかなり追いやすくなった。次は勝率係数を足すより、planner が勝った 1 戦と負けた 5 戦を比較し、以下を分けて監査するのがよい。

- planner が白より良かった差分: マスターアタック撃破、前倒し盤面処理、盾対象差分。
- planner が白より悪かった差分: 非リーサル顔打点、削りを捨てた召喚、攻撃可能状態での `end_turn`、移動/召喚で攻撃権を失う手。
- 探索で読むべき最終盤面: 自ターン終端だけでなく、「相手ターン後に自分の次ターンがどの程度残るか」。

## 次フェーズ案

次は `white_planner` をそのまま強くするより、今回の差分基盤で loss audit を追加する。

1. `benchmark:ai --write-artifacts` で `white_planner` 負け 5 戦の履歴を保存する。
2. planner-selected diff を、攻撃 / 召喚 / focus / move / master action ごとに集計する。
3. 負け履歴から「攻撃可能なのにターン終了」「削りより召喚」「顔打点で盤面放置」を抽出する。
4. 修正候補は係数ではなく、planner の採用ゲート条件へ落とす。
5. `white` 置換ではなく、`white_planner` は実験プロファイルのまま維持する。
